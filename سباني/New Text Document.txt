📚 الخطة الأكاديمية التفصيلية:
الدرس 1: 🏰 Castillo de Segovia - أجزاء الجسم
القواعد الجديدة: أدوات الإشارة (Este/Esta/Esto) + الضمير المتصل (mi/mis)
لماذا؟ أول حاجة الطفل يتعلمها هي يشاور على حاجة ويقول "ده إيه" - ده أساس أي لغة.

المجموعة	الجرامر	أمثلة الجمل
1 - الوجه	Este/Esta es mi + جزء	Este es mi ojo (ده عيني) / Esta es mi boca (دي بقي)
2 - الجسم العلوي	Estos/Estas son mis + أجزاء	Estos son mis brazos (دول ذراعاتي)
3 - الجسم السفلي	¿Qué es esto? Es mi + جزء	¿Qué es esto? Es mi pie (ايه ده؟ ده رجلي)
15 كلمة:

text

الوجه:    ojo, boca, nariz, oreja, cabeza
العلوي:   brazo, mano, dedo, hombro, cuello
السفلي:   pierna, pie, rodilla, espalda, cuerpo
تدرج الجرامر:

text

1. Este es mi ojo          (ده عيني)        ← مفرد مذكر
2. Esta es mi boca         (دي بقي)         ← مفرد مؤنث  
3. Estos son mis ojos      (دول عينيا)      ← جمع مذكر
4. Estas son mis orejas    (دول ودانيا)     ← جمع مؤنث
5. ¿Qué es esto? Es mi pie (ايه ده؟ ده رجلي) ← السؤال
الدرس 2: 👗 Museo del Traje - الملابس
القواعد الجديدة: أدوات التعريف (el/la/los/las) + فعل Ser (es) مع الصفات
لماذا؟ بعد ما الطفل اتعلم يشاور (este/esta)، يتعلم يوصف (el/la + es + صفة)

المجموعة	الجرامر	أمثلة الجمل
1 - علوية	La/El + ملابس	La camisa (القميص) / El vestido (الفستان)
2 - سفلية	El/La + ملابس + es + لون	La falda es roja (التنورة حمرا)
3 - إكسسوارات	El/La + ملابس + es + صفة	El sombrero es grande (القبعة كبيرة)
15 كلمة:

text

علوية:      camisa, camiseta, suéter, chaqueta, vestido
سفلية:      pantalón, falda, zapatos, calcetines, botas
إكسسوارات:  sombrero, bufanda, guantes, gafas, mochila
تدرج الجرامر:

text

1. La camisa               (القميص)         ← أداة تعريف مؤنث
2. El vestido              (الفستان)        ← أداة تعريف مذكر
3. La falda es roja        (التنورة حمرا)    ← Ser + صفة لون
4. El sombrero es grande   (القبعة كبيرة)    ← Ser + صفة وصفية
5. Los zapatos son negros  (الجزم سودا)      ← جمع + Ser
الدرس 3: 🍖 Mesón de Cándido - الطعام
القواعد الجديدة: أدوات التنكير (un/una) + فعل Ser مع الطعام + Me gusta (يعجبني)
لماذا؟ بعد التعريف (el/la)، يتعلم التنكير (un/una) والتعبير عن الرأي (يحب/مش بيحب)

المجموعة	الجرامر	أمثلة الجمل
1 - أكل	Esto es + un/una + طعام	Esto es un pan (ده عيش)
2 - شرب	Esto es + un/una + شراب	Esto es una leche (ده لبن)
3 - رأي	Me gusta + el/la + طعام	Me gusta el pan (بحب العيش)
15 كلمة:

text

أكل:    pan, arroz, pollo, pescado, huevo
شرب:    agua, leche, zumo, sopa, té
رأي:    manzana, plátano, queso, galleta, helado
تدرج الجرامر:

text

1. Esto es un pan          (ده عيش)         ← تنكير مذكر
2. Esto es una manzana     (دي تفاحة)       ← تنكير مؤنث
3. El pan es bueno         (العيش حلو)       ← تعريف + صفة
4. Me gusta el pan         (بحب العيش)       ← Me gusta 🆕
5. No me gusta el pescado  (مش بحب السمك)    ← النفي 🆕
الدرس 4: 🎓 Universidad de Salamanca - المدرسة
القواعد الجديدة: الضمائر (Yo, Tú, Él, Ella) + فعل Ser الكامل + Hay (فيه)
لماذا؟ بعد الأساسيات، يتعلم الضمائر وأول تصريف حقيقي

المجموعة	الجرامر	أمثلة الجمل
1 - أشخاص	Yo soy + اسم/صفة	Yo soy Ahmed (أنا أحمد)
2 - أدوات	Hay + un/una + أداة	Hay un libro (فيه كتاب)
3 - أماكن	El/La + مكان + es + صفة	La clase es grande (الفصل كبير)
15 كلمة:

text

أشخاص:   alumno, profesor, amigo, niño, niña
أدوات:   libro, lápiz, bolígrafo, cuaderno, mochila
أماكن:   clase, escuela, mesa, silla, pizarra
تدرج الجرامر:

text

1. Yo soy alumno           (أنا تلميذ)      ← الضمير Yo + Ser
2. Tú eres mi amigo        (انت صاحبي)      ← الضمير Tú + Ser
3. Él es el profesor       (هو الأستاذ)      ← الضمير Él + Ser
4. Hay un libro            (فيه كتاب)        ← Hay 🆕
5. ¿Hay un lápiz?          (فيه قلم؟)        ← سؤال بـ Hay 🆕
الدرس 5: 🏚️ Casas Colgadas - المنزل
القواعد الجديدة: فعل Estar (Yo estoy, Tú estás) + حروف الجر (en, sobre, debajo)
لماذا؟ الفرق بين Ser و Estar أساسي في الإسبانية، وحروف الجر مع الموقع

المجموعة	الجرامر	أمثلة الجمل
1 - الغرف	Esto es + el/la + غرفة	Esto es la cocina (دي المطبخ)
2 - الأثاث	El/La + أثاث + está en + مكان	La cama está en mi cuarto (السرير في أودتي)
3 - الموقع	¿Dónde está? Está + حرف جر	¿Dónde está? Está en la mesa (فين؟ على الطربيزة)
15 كلمة:

text

غرف:     cocina, baño, salón, dormitorio, jardín
أثاث:    cama, mesa, silla, sofá, lámpara
مواقع:   puerta, ventana, escalera, techo, suelo
تدرج الجرامر:

text

1. Esto es la cocina       (دي المطبخ)       ← مراجعة Esto es
2. Yo estoy en la cocina   (أنا في المطبخ)    ← Estar + en 🆕
3. El gato está en la cama (القط على السرير)   ← Estar للموقع 🆕
4. ¿Dónde está el gato?    (القط فين؟)        ← سؤال Dónde 🆕
5. Está debajo de la mesa  (تحت الطربيزة)     ← حروف الجر 🆕
الدرس 6: 🎨 Museo del Greco - المشاعر
القواعد الجديدة: Estar + صفة مشاعر + ¿Cómo estás? (حالك ازاي؟)
لماذا؟ بعد ما تعلم Estar للموقع، يتعلمها للمشاعر - التطبيق الثاني لـ Estar

المجموعة	الجرامر	أمثلة الجمل
1 - مشاعر إيجابية	Yo estoy + صفة	Yo estoy feliz (أنا مبسوط)
2 - مشاعر سلبية	Él/Ella está + صفة	Ella está triste (هي زعلانة)
3 - سؤال وجواب	¿Cómo estás? Estoy + صفة	¿Cómo estás? Estoy bien (حالك ازاي؟ كويس)
15 كلمة:

text

إيجابية:   feliz, contento, bien, alegre, tranquilo
سلبية:     triste, enfadado, cansado, enfermo, asustado
حالات:     hambriento, sediento, aburrido, nervioso, sorprendido
تدرج الجرامر:

text

1. Yo estoy feliz          (أنا مبسوط)      ← مراجعة Estar
2. Tú estás triste         (انت زعلان)       ← Estar مع مشاعر
3. Él está cansado         (هو تعبان)        ← Estar مع ضمائر
4. ¿Cómo estás?            (حالك ازاي؟)      ← السؤال 🆕
5. Estoy bien, gracias     (كويس، شكراً)     ← الرد الكامل 🆕
الدرس 7: ⛲ Plaza Mayor - الألعاب والهوايات
القواعد الجديدة: فعل Tener (Yo tengo) + فعل Querer (Yo quiero) + Me gusta مراجعة
لماذا؟ بعد Ser و Estar، يتعلم Tener (عندي) و Querer (عايز) - الأفعال الأساسية الأربعة

المجموعة	الجرامر	أمثلة الجمل
1 - ألعاب	Yo tengo + un/una + لعبة	Yo tengo una pelota (عندي كورة)
2 - هوايات	Me gusta + فعل مصدر	Me gusta jugar (بحب ألعب)
3 - طلبات	Yo quiero + فعل/اسم	Yo quiero jugar (عايز ألعب)
15 كلمة:

text

ألعاب:    pelota, muñeca, coche, puzzle, bicicleta
هوايات:   jugar, pintar, cantar, bailar, leer
طلبات:    correr, nadar, saltar, dibujar, cocinar
تدرج الجرامر:

text

1. Yo tengo una pelota     (عندي كورة)       ← Tener 🆕
2. Tú tienes un coche      (عندك عربية)      ← Tener تصريف 🆕
3. Me gusta jugar           (بحب ألعب)       ← Me gusta + مصدر
4. Yo quiero jugar          (عايز ألعب)      ← Querer 🆕
5. ¿Quieres jugar?          (عايز تلعب؟)     ← سؤال Querer 🆕

interface SpanishLessonItem {
  // الكلمة الأساسية
  word: string;                    // ojo
  wordAr: string;                  // عين
  emoji: string;                   // 👁️
  
  // الجملة الكاملة
  sentenceEs: string;              // "Este es mi ojo"
  sentenceAr: string;              // "ده عيني"
  sentenceWords: string[];         // ["Este", "es", "mi", "ojo"]
  sentenceDistractors: string[];   // ["una", "la", "tu"]
  
  // شرح الجرامر
  grammarHint: {
    pattern: string;               // "Este + es + mi + اسم"
    patternAr: string;             // "ده + هو + بتاعي + اسم"
  };
  
  // التصميم
  category: string;
  categoryAr: string;
  color: string;
  gradient: [string, string];
}
