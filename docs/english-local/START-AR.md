# تجربة الإنجليزي من Visual Studio Code على ويندوز

النسخة الجديدة خاصة بالمالك ومن غير حفظ تقدم أو نقاط. الموقع الأونلاين لم يتحدث بعد. لا تحتاج نشرًا لمراجعتها على جهازك.

أنت تستخدم `npm run dev` بالفعل، فلا تحتاج تثبيت الأدوات من البداية. قبل تحديث مجلدك الحالي، راجع `git status --short --branch` و`git remote -v`. لا تعمل reset أو تمسح تعديلاتك. لو عندك شغل غير محفوظ أو الفرع مختلف، احتفظ به وحدّث في نسخة منفصلة بعد تحديد الحالة.

بعد وصول ملفات التحديث إلى مجلدك، شغّل `npm run dev` كالمعتاد. افتح عنوان الجهاز المحلي الذي يظهر في Terminal. سجّل دخولك بحساب المالك من صفحة الدخول المحلية، ثم ارجع للرئيسية واضغط كتاب الإنجليزي. حساب المالك المتحقق منه يفتح اختيار البطل والاسم المستعار، ثم الخريطة الأولى. يوجد رابط منفصل للإنجليزي القديم. غير المالك يظل على المسار القديم.

الاسم والشخصية مؤقتان في ذاكرة الصفحة فقط. الانتقال بين الخرائط من داخل المغامرة يحتفظ بهما، وإعادة تحميل الصفحة تمسحهما. الأسهم والقائمة المنسدلة تبدّل الخرائط. داخل الدرس تقدر ترجع للكلمات أو للنشاط السابق. الرجوع للنشاط يعيد المحاولة المؤقتة من عنده؛ لا يضيف نقاطًا أو مكافآت.

لو اتصال الحسابات الحالي مضبوط عندك، احتفظ بملف `.env.local` الموجود. لا تشاركه في الرسائل. المعاينة تحتاج فقط `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` لنفس مشروع Supabase الحالي، ولا تحتاج مفتاح service_role أو SQL. اكتب كلمة السر في صفحة الدخول فقط. لا تعطّل تحقق المالك لو الدخول رفض؛ وقتها نراجع الرسالة من غير أسرار.

الصوت مرفق. جرّبه على سماعات جهازك. المايك اختياري وبموافقة واضحة، يعتمد على دعم المتصفح، وليس تقييم نطق. لا تفتح نفقًا عامًا ولا منفذ الراوتر. لإيقاف التشغيل اضغط Ctrl+C.
